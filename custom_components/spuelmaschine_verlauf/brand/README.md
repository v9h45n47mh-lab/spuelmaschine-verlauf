# Markenbild

Eigenes Spülmaschinen-Symbol mit Teller und Erledigt-Häkchen, transparenter Hintergrund. Mit dem integrierten Bildgenerator erzeugt, anschließend ohne Motivänderung auf die offiziellen Bildgrößen exportiert. Quadratische Marke: HA verwendet das Icon auch als Logo (kein separates logo.png erforderlich).

Prompt: Modern dishwasher silhouette with a plate inside and a completion checkmark integrated into the lower right corner. Clean readable app icon at small sizes, teal-blue and deep navy with mint accent, centered, no lettering, no Home Assistant branding, genuine transparent background.

- icon.png: 256 × 256 PNG mit Alpha
- icon@2x.png: 512 × 512 PNG mit Alpha
